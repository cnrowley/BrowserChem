Implicit solvation (GB/SA)

Generalized Born (HCT) electrostatics + a SASA-based nonpolar term. Needs MBIS partial charges (load & run "MBIS partial charges" above) and an already-optimized 3D conformer. A real, from-scratch physics calculation, not a trained/fit model — see this section's info note for what's simplified.

Aqueous pKa & titration curve

Detects ionizable groups by SMARTS pattern matching, looks up each site's pKa from a trained model, then computes a titration curve treating sites as independent (no site-site electrostatic coupling) — a standard, documented simplifying assumption, not a hidden one.

LogD (pH 7)

Standard Henderson–Hasselbalch correction to LogP: uses each detected site's own pKa (independent-site model, same as the curve above) to find the population fraction of the fully neutral (un-ionized) species at pH 7, converts that into the Gibbs free energy cost of forcing the molecule into that neutral state against its actual pH-7 equilibrium (ΔG = −RT·ln(fraction neutral)), then applies the equivalent LogP shift: logD = logP + log₁₀(fraction neutral) = logP − ΔG / (RT·ln 10). LogP is whichever's currently available for the drawn structure (a loaded LogP model, else RDKit's own Crippen LogP) — draw the neutral/un-ionized form for this to be meaningful, same assumption the LogP value itself already makes.

Dominant microstate by pH

Of every possible combination of protonated/deprotonated sites (independent-site model, same assumption as the curve above), the species that's actually the majority population at each pH -- most of the 2^N possible combinations are never the majority anywhere and are omitted.
